# Security Plan

Production requirements:
- MFA
- RBAC and least privilege
- Encryption in transit and at rest
- Strong password hashing
- Audit trails
- Session/device controls
- Secure backups
- Disaster recovery
- Consent management
- Data retention/deletion workflows
- File access authorization
- API rate limiting
- Monitoring and incident response
- Privacy/legal review for applicable Indian requirements

Never use demo credentials or demo storage for patient data.
